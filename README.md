An entry for the make.fun bounty
[Two Robots in an Elevator](https://make.fun/bounty/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f):
one line of awkward small talk that one robot says to another while they
ride an elevator together.

## The line

> I pressed every floor button so someone else will get on and talk to you first.

## Why it should land

The joke works because the robot's solution to social discomfort is pure
machine logic: faced with a stranger in a lift, it does not make
conversation, it presses every floor button. That sounds like a glitch
until the second half of the sentence reveals it was deliberate — the
robot rigged the ride so a third passenger would board and be forced to
speak first. And the confession is delivered to the very robot it is
avoiding, which is the awkward part: it tells its fellow passenger, to
its face, that it went out of its way not to talk to it.

It is one sentence, seventy-nine characters, with the punch landing on the
last three words. Nothing is wasted, nothing needs a second read, and
there is no beep-boop pun in sight.

## How to run

```sh
python3 main.py
```

That writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output`
by default), exactly as written, with no trailing newline. The program
then reads the file back and checks it matches the line, is a single
line, and stays inside the 1–200 character gate.
